### --------------------------------------------------
### ÉTAPE 1 : Récupérer automatiquement les IDs
### --------------------------------------------------

### 1.1 Récupérer la première communauté
GET {{baseUrl}}/api/communities
> {%
    if (response.body && response.body.length > 0) {
        client.global.set("communityId", response.body[0].id);
        client.log("✅ Community ID récupéré: " + response.body[0].id);
    } else {
        client.log("❌ Aucune communauté trouvée !");
    }
%}

### 1.2 Récupérer le premier utilisateur
GET {{baseUrl}}/api/auth/me
> {%
    if (response.body && response.body.user) {
        client.global.set("userId", response.body.user.id);
        client.log("✅ User ID récupéré: " + response.body.user.id);
    } else {
        client.log("⚠️ Non authentifié. Inscrivez-vous d'abord avec la requête ci-dessous.");
    }
%}
